# Third-party notices

Kode itself is licensed under the Apache License 2.0 ([LICENSE](LICENSE));
this file covers the code it links, not Kode's own source.

A release archive contains `kode`, and every program built with `kode build`
embeds the Kode runtime. Both therefore distribute object code from the
37 crates below, and their licenses require their notices to travel with it.
Ship this file together with `LICENSE` when you redistribute a Kode binary.

Where a crate declares a choice (`A OR B`), Kode uses it under a license that
is compatible with Apache-2.0; the declaration is reproduced as published.

Generated by `scripts/third-party-notices.py` from `Cargo.lock`. Do not edit:
run the script after changing a dependency, and
`python3 scripts/third-party-notices.py --check` (which CI runs) verifies it.
